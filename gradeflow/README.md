# GradeFlow
وب‌اپ استاتیک مدیریت نمرات (HTML/CSS/JS خالص، ذخیره در localStorage).
اجرا: پوشه را روی GitHub Pages / Netlify / هر هاست استاتیک بگذارید (یا با `python3 -m http.server` باز کنید؛ ورود رمزدار به HTTPS یا localhost نیاز دارد).
نیازمند اینترنت برای: فونت Vazirmatn، Chart.js و SheetJS (از CDN). PDF با چاپ A4 مرورگر («ذخیره به‌صورت PDF») ساخته می‌شود.
ورود فقط برای استفاده شخصی روی همین مرورگر است و سیستم احراز هویت امن نیست؛ رمز با PBKDF2 هش می‌شود.
